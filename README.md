# MyTarget

Статический сайт-презентация для партнёров. HTML, CSS, JavaScript и встроенные SVG; без внешних зависимостей, регистрации и базы данных.

Откройте `index.html` в браузере. Для публикации на GitHub Pages загрузите содержимое этой папки в репозиторий, затем выберите Settings → Pages → Deploy from a branch → main / root.

Содержание основано на предоставленном плане. Миниатюры интерфейсов и иллюстрации обозначены как демонстрационные. Тариф BASIC обсуждается; разрешения Meta требуют уточнения.

Сайт поддерживает мобильную раскладку, клавиатурную навигацию и prefers-reduced-motion.
