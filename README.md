# MyTarget — мобильная презентация

Откройте index.html. Все иконки и иллюстрации встроены в HTML. Внешних библиотек и шрифтов нет.

Для GitHub Pages загрузите содержимое папки в корень репозитория и выберите Settings → Pages → Deploy from a branch → main / root.

Отдельно доступен MyTarget-mobile.html: весь сайт в одном файле, включая стили и JavaScript.

Сценарии выручки: 100 / 1 000 / 10 000 платящих подписчиков PRO по 25 000 ₸ ежемесячно. Год = 12 месяцев при неизменном числе подписчиков; расходы, налоги, курс и подключение не включены.
